# לוח יהודי

אפליקציה בעברית לניהול סדר היום היהודי, זמני היום, משימות ותזכורות. נבנית כיישום Web/PWA עם תכנון להרחבה ל-Windows באמצעות Electron ול-Android באמצעות Capacitor.

## הרצה מקומית

1. התקינו Node.js בגרסת LTS.
2. הריצו `npm install`.
3. הריצו `npm run dev` ופתחו את כתובת localhost שמופיעה בטרמינל.
4. לבדיקת בנייה: `npm run build`.

## מצב הפיתוח

- ממשק React + TypeScript, עברית ו-RTL.
- תצוגת יום, תאריך עברי, שעון, משימות ושמירה מקומית בדפדפן.
- זמני היום כרגע נתוני הדגמה בלבד — אין להשתמש בהם לצורך הלכתי.
- טרם חוברו מנוע זמני הלכה, אימות Google, שרת, מסד נתונים או סנכרון יומן.

## אבטחה וחשבונות

מצב אורח שומר נתונים בדפדפן הנוכחי בלבד. שמירה בענן תדרוש התחברות Google. הרשאת Google Calendar תתבקש בנפרד ורק אם המשתמש יבחר להפעיל סנכרון. אין לשמור מפתחות סודיים במאגר הציבורי.
